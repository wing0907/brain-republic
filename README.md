# 두뇌공화국: 뇌 속 왕국 키우기 (Brain Republic)

> 당신의 뇌는 1,428개 부서가 일하는 거대한 공화국.
> 주인의 의식에 자주 등장하는 시민만이 살아남습니다.

**NAN 2026 — NHN Game × AI Hackathon** 사전 과제(예선) 출품작 · 팀 **뇌지컬연구소**.
인간의 뇌를 거대한 행정 공화국으로 의인화한 오리지널 세계관 **「두뇌공화국」** 을
모바일 경영·육성 게임으로 옮긴 작품입니다.

## 게임 소개

아이소메트릭 뇌 대륙 위, 6개 국(局)의 청사와 국장 크리처들이 당신의 관심을
기다립니다.

- **돌보기**: 코인으로 국장을 먹이고 재우면 「인지도」가 오릅니다.
  인지도 = 주인의 의식에 등장하는 빈도 = **시민의 수명**.
- **성장**: 청사를 증축할수록 활성 부서가 늘어 1,428개 부서 완성에 다가갑니다.
- **일하기**: 국별 에피소드 18편과 돌발상황을 미니게임(조각 맞추기 퍼즐,
  위기 대응)으로 해결해 코인·다이아를 모으세요.
- **생존**: 방치하면 게이지가 떨어지고, 인지도 0이면 국장이 위독해지며,
  오래 잊혀지면 **소멸**합니다 — 새 국장이 부임하고 그 국은 처음부터.
- 6개 국을 모두 완성하면 「두뇌공화국 완성」 엔딩.

(v1 아케이드 버전 「면접 대작전」은 `v0.1-arcade` 태그에 보존되어 있습니다.)

## 개발

```bash
npm install
npm run dev     # 로컬 개발 서버
npm run build   # dist/ 프로덕션 빌드
```

- 엔진: [Phaser 3](https://phaser.io/) + Vite
- 그래픽/사운드: 외부 에셋 없이 전량 프로시저럴 생성(코드 드로잉 + WebAudio 신스)
- AI 활용: 기획·코드·밸런싱 전 과정을 Claude Code로 진행 — 상세 내역은 `docs/AI_TECH_DOC.md`
- 데모 세이브(시연용): `?demo=doom`(방치 소멸 연출) · `?demo=rich`(후반부) ·
  `?demo=ending`(엔딩) · `?demo=fresh`(초기화)

## 저장소 구조

```
src/
  main.js          진입점, Phaser 설정
  config.js        경제·게이지·소멸 밸런스 상수
  data/            세계관 데이터(6개 국·국장·위기), 에피소드 18편
  scenes/          Boot/Title/Map/Bureau/Episode/Puzzle/CrisisMini/Ending
  systems/         프로시저럴 아트(art/art2), WebAudio 신스, 세이브/방치 정산, 보상
docs/              기획서(GDD), 제출 문서, AI 활용 기술 문서
```
