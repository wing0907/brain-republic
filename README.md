# 두뇌공화국: 면접 대작전 (Brain Republic: Interview Crisis)

> 당신의 뇌 속 1,428개 부서가 오늘도 야근합니다. 면접 3분, 멘탈을 사수하라!

**NAN 2026 — NHN Game × AI Hackathon** 사전 과제(예선) 출품작.
인간의 뇌를 거대한 행정 공화국으로 의인화한 오리지널 세계관 **「두뇌공화국」** 을
모바일 아케이드 게임으로 옮긴 작품입니다.

## 게임 소개

주인공은 인생 최대의 면접장에 앉아 있습니다. 겉으로는 침착해 보이지만,
뇌 속 공화국의 6개 국(局)은 초비상 사태.

- **기억인지국** — "지원 동기 서류가 없습니다!" (기억 분실)
- **신체반응국** — "손발 저림 수치 폭주!"
- **감정사회국** — "눈물 게이트 붕괴 직전!"
- **충동관리국** — "핸드폰 확인 충동 유입!"
- **언어표현국** — "말실수 파일 발송 3초 전!"
- **수면상상국** — "공상 구름이 상영을 시작했습니다!"

플레이어는 뇌정부청사의 위기관리 총괄이 되어, 밀려드는 부서별 위기를
**탭 · 홀드 · 스와이프**로 해결하며 3분의 면접 동안 멘탈 게이지를 사수해야 합니다.

## 플레이

- **플레이 링크**: (배포 후 기입 — GitHub Pages)
- 모바일 브라우저(세로 화면)에 최적화. 데스크톱에서는 마우스로 플레이 가능.

## 개발

```bash
npm install
npm run dev     # 로컬 개발 서버
npm run build   # dist/ 프로덕션 빌드
```

- 엔진: [Phaser 3](https://phaser.io/) + Vite
- 그래픽/사운드: 외부 에셋 없이 전량 프로시저럴 생성(코드 드로잉 + WebAudio 신스)
- AI 활용: 기획·코드·밸런싱 전 과정을 Claude Code로 진행 — 상세 내역은 `docs/AI_TECH_DOC.md`

## 저장소 구조

```
src/
  main.js          진입점, Phaser 설정
  data/            세계관 데이터(6개 국, 부서, 위기 이벤트)
  scenes/          Boot / Title / Game / Result 씬
  systems/         프로시저럴 아트, WebAudio 사운드
docs/              기획서(GDD), 제출 문서, AI 활용 기술 문서
```
