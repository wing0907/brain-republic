## 게임

- **협력 콤보**: 민원마다 필요한 부서를 순서대로 호출 → 담당자가 달려와 부서별
  조작(연타/홀드/스와이프/결재)을 함께 수행해야 해결
- **명예 시스템**: 활약한 부서는 뇌보도국 뉴스에 출연 → 인지도 상승 → 도시 성장
- **나라 키우기**: 급여(뇌화)로 6개 국 청사를 확장, 1,428개 부서를 향해
- 픽셀아트·사운드 전량 코드 생성 (외부 에셋: Galmuri 폰트 1종, OFL)

## 개발

```bash
npm install
npm run dev      # 로컬 개발
npm run build    # 프로덕션 빌드
npm run deploy   # GitHub Pages 배포
npm run docs     # 제출 PDF 생성
```
