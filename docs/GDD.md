# 두뇌공화국: 뇌 속 왕국 키우기 — 게임 디자인 문서 (GDD)

- 프로젝트: NAN 2026 (NHN Game × AI Hackathon) 사전 과제 — "AI를 활용한 게임 제작"
- 플랫폼: 모바일 웹 (세로 720×1280, 브라우저 즉시 실행) / 데스크톱 마우스 지원
- 장르: 경영·육성 (왕국 키우기) + 미니게임
- 원작 세계관·기획: **성지은(팀원)** — 「두뇌공화국」, 인간의 뇌를 1,428개 부서를
  가진 행정 공화국으로 의인화한 오리지널 IP. 본 게임은 성지은의 기획에서 탄생.
- 버전 이력: v1 아케이드(태그 `v0.1-arcade`) → 팀 피드백으로 **v2 왕국 키우기** 전면 개편

---

## 1. 컨셉

> 당신의 뇌는 오늘도 출근한 1,428개 부서의 공화국.
> 주인의 의식에 등장하지 못하는 시민은… 조용히 잊혀진다.

플레이어는 두뇌공화국의 새 관리자. 아이소메트릭 뇌 대륙 위 6개 국(局) 청사를
성장시키고 국장 크리처들을 돌보며, 에피소드와 돌발상황을 해결해 공화국을
완성한다. **원작 설정을 장식이 아니라 게임 규칙으로 직역**한 것이 핵심:

| 원작 설정 | 게임 시스템 |
|---|---|
| 뇌 내 화폐 경제 (시민도 먹고 자야 함) | 코인 수익 → 먹이기/재우기/증축에 소비 |
| 명예 시스템: 자주 등장 → 뇌 건강·생명 | **인지도 게이지 = 수명** (0 → 위독 → 소멸) |
| 1,428개 부서 | 청사 레벨업마다 활성 부서 증가 (238×6) |
| 부서 간 알력·위기 대응 다큐 | 에피소드 18편 + 랜덤 돌발상황 + 미니게임 |
| 종족별 신체 특징 (아트 디렉션) | 국장 크리처 6종의 프로시저럴 디자인 |

## 2. 코어 루프

```
[돌보기] 먹이기·재우기 → 배부름·컨디션 ↑ → 인지도(수명) ↑
    ↓                                        ↓
[수익] 인지도 비례 코인 수익 (방치 50%)   [생존] 방치 → 게이지 ↓ → 위독 → 소멸(세대교체)
    ↓
[성장] 청사 증축(Lv.1→5) → 활성 부서 ↑ → 수익 ↑
    ↓
[일하기] 에피소드·돌발상황 → 미니게임 → 코인·다이아·인지도 보상
    ↓
[완성] 국 완성(Lv.5 + 에피소드 3편) ×6 → 1,428개 부서 → 공화국 완성 엔딩
```

## 3. 화면 구성

- **지도(Map)**: 아이소메트릭 뇌 대륙 + 6개 국 청사(레벨별 층수 성장).
  상단 HUD(코인/다이아/초당 수익/활성 부서/뇌 건강), 하단(다이아 부스트/도움말).
  돌발상황 경보(⚠)가 건물 위에 랜덤 팝업.
- **국 상세(Bureau)**: 국장 크리처(성장 3단계) + 청사, 게이지 3종(배부름/컨디션/
  인지도), 액션 버튼(먹이기/재우기/증축/에피소드/긴급 업무).
- **에피소드(Episode)**: 국장·기자·뇌정부청사의 대사 연출 → 미니게임 → 보상.
- **미니게임**: 조각 맞추기 퍼즐(3×3 문장 복원 드래그) / 위기 대응(연타·홀드·
  스와이프·2지선다 5라운드, 3건 이상 성공).
- **엔딩(Ending)**: 6국 완성 시 국장 단체 사진 + 폭죽 + "공화국의 하루는 계속된다".

## 4. 생존 규칙 — "인지도 = 수명" (핵심 차별점)

원작의 명예 시스템("주인의 의식에 자주 등장할수록 오래 산다")을 리텐션 루프로 설계:

- 배부름·컨디션 60 이상 유지 → 인지도 상승 / 20 이하 방치 → 인지도 하락
- **인지도 0 = 위독**: 해당 국 수익 정지, 크리처 회색화. 돌봄·미니게임으로 회생 가능.
- **접속하지 않는 시간**에도 게이지가 깎인다(시간당 배부름 -7, 컨디션 -6, 바닥나면
  인지도 -9). 인지도 0으로 12시간 이상 방치 → **국장 소멸**: 새 국장 부임 + Lv.1 초기화.
- 접속해서 돌보는 행위 자체가 "주인이 뇌에 관심을 주는 것"이라는 메타 서사.

## 5. 경제 밸런스

| 항목 | 수치 |
|---|---|
| 초당 수익 | Σ 레벨 × 1.2 × (0.4 + 0.6×인지도/100), 위독 국 제외 |
| 방치 수익 | 50% 효율, 최대 8시간 |
| 먹이기/재우기 | 60 코인, 게이지 +34 |
| 증축 비용 | 400×Lv² (400/1,600/3,600/6,400) |
| 에피소드 보상 | 300 코인 + 💎1 + 인지도 +22 |
| 돌발상황 보상 | 440 코인(×2 배율) + 인지도 +22 / 무시 시 인지도 -10 |
| 국 완성 | 💎5 / 다이아 부스트(💎3): 전국 게이지 +30, 위독 회생 |

## 5.5 스킬 루프 — 야근 러시 & 스파이 색출

경영 루프만으로는 세션 내 긴장·실력 표현이 부족하다는 팀 플레이테스트 결론에 따라
두 개의 스킬 모드를 추가:

- **야근 러시(엔드리스 아케이드)**: 지도 중앙 뇌정부청사 입장. v1 아케이드의 위기
  카드 조작(연타/홀드/스와이프/2지선다)을 계승하되 무한 웨이브 — 시간에 따라 스폰
  간격 2.4s→0.9s, 카드 수명 6s→3.2s, 동시 카드 2→5로 가속. 멘탈 0 = 번아웃.
  **왕국 연동**: 점수 배율 = 1 + 0.05×Σ국레벨(최대 ×2.5), 점수는 코인(÷8)·
  다이아(5,000점당 1, 최대 3)·전 국 인지도(+8)로 환원 — 경영↔아케이드 상호 강화.
- **스파이 색출(싱글 추리)**: 돌발상황의 35%는 보라 경보 = 감사실 이벤트.
  국장 5명의 증언 중 스파이는 "OO와 함께 있었다"는 거짓 알리바이를 대고, 당사자는
  "혼자 있었다"고 증언 — 모순을 찾아 25초 안에 지목. 성공 💎1+코인 / 실패·시간초과
  시 스파이 도주 + 전 국 인지도 감소. 사회적 추리 게임의 정수를 1인용으로 번안.

## 6. 에피소드 (콘텐츠)

국별 3편 × 6국 = 18편. 구조: 대사 2줄(국장/기자/뇌정부) → 미니게임 → 아웃트로.
원작의 부서 개그를 콘텐츠 축으로: 눈물 댐 정기 점검, 금단의 야식 봉인구역,
꿈 상영관 복구, 침묵 방지 훈련… 데이터(`src/data/episodes.js`) 분리로 증량 용이.

## 7. 아트 디렉션

원작 가이드(뇌 주름 지형, 노을빛 오렌지-핑크, 유기적 자연) 기반. **외부 에셋 0**.
- 지형: 아이소메트릭 다이아 대륙 + 뇌 주름 능선 + 반딧불이 입자
- 건물: 국 고유색 아이소 청사, 레벨=층수, 창문 불빛·깃발
- 크리처: 원작 종족 설정을 코드 드로잉으로 — 기억(나이테 무늬·큰 귀), 신체(덩굴
  힘줄), 감정(반투명), 충동(발광 돌기), 언어(안테나 귀), 수면(반딧불 점).
  성장 2단계 명찰, 3단계 왕관.
- 사운드: WebAudio 신스 16종 (코인, 레벨업 팡파레, 퍼즐 스냅, 소멸 경고 등)

## 8. 기술 설계

- Phaser 3 + Vite. 씬: `Boot → Title → Map ⇄ Bureau ⇄ Episode ⇄ (Puzzle|CrisisMini)`, `Ending`
- 상태: Phaser registry 공유 + `localStorage` 세이브(5초 주기 + 씬 전환 + 백그라운드 전환 시)
- 방치 정산: 재접속 시 경과 시간으로 수익·게이지 감소·소멸을 일괄 시뮬레이션
- 데이터 주도: 세계관(`bureaus.js`)·에피소드(`episodes.js`)·밸런스(`config.js`) 분리
