## 1. 컨셉

> 목표가 상충하는 부서들은 오늘도 다툰다 (W7).
> 그 다툼이… 결재 도장 포격전이라면?

플레이어 = **핸드폰중독관리팀** (원작에 명시된 알력 당사자). 주인님의 평온을
위협하는 여섯 부서와 1:1 턴제 포격 — 검증된 고전 문법이라 규칙 설명이 10초면
끝나고, 바람·지형이 매 판을 다르게 만든다.

## 2. 코어 루프

```
라운드 인트로(알력 매치업 코믹 소개)
 → [내 턴] 드래그 조준(궤적 미리보기) → 발사 → 탄도(중력+바람) → 폭발
    · 직격 34+α / 스플래시 최대 26 (자기 피해 가능)
    · 지형 크레이터 → 유닛 재정착(굴러떨어짐)
 → [AI 턴] 탐색 기반 조준 + 라운드별 오차(±16° → ±3.5°)
 → HP 0 → 승리/패배 → 다음 알력 상대 (총 6라운드) → 전 부서 평정
```

## 3. 시스템

| 시스템 | 설계 | 세계관 근거 |
|---|---|---|
| 바람 | 매 턴 -90~+90 랜덤 가속, HUD에 "주인님의 변덕"으로 표시 | 주인의 기분이 뇌 내 환경을 바꾼다 |
| 지형 | 하이트맵(사인 합성) 랜덤 생성, 크레이터 파괴, 표면은 노을빛 발광 능선 | W9 뇌 주름 지형 |
| 포탄 | 결재 도장 (회전하며 비행, 파티클 트레일) | 행정 패러디(W1) |
| 매치업 | 야식욕구팀·이불킥재생팀·월요일공포팀·아무말대잔치팀·백일몽제작팀 등 — 각 국 소속·색·도발 대사 | W7 알력 + 1,428 부서(W6) |
| AI | 60샘플 탄도 탐색 후 최적해에 라운드별 오차 적용 | — |

## 4. 조작·타격감

- 슬링샷 드래그(앵그리버드 문법) — 모바일에서 설명 불필요.
- 점선 궤적 미리보기 + 파워 게이지 호 + 포신 회전.
- 폭발: 파티클 26발 + 확장 링 + 카메라 셰이크(직격 시 강화) + 피해 플로팅.
- 발사 반동, 유닛 흔들림, 도발 말풍선, 승리 시 "결재 서류에 깔렸다!" 연출.

## 5. 아트/사운드

- 스무스 벡터 스타일(픽셀 아님): 노을 그라데이션 하늘 + 대형 태양 글로우 +
  구름, 국별 컬러 블롭 마스코트(포신 장착), 전량 코드 드로잉.
- 사운드: WebAudio 합성 — 발사(포슝)/폭발(쾅)/직격/승패 징글 + 긴장감 있는
  마이너 펜타 BGM. 외부 에셋 0 (폰트 파일도 미사용 — 시스템 폰트 스택).
