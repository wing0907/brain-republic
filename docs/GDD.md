## 1. 컨셉 (W1·W2·W3)

> 당신은 오늘 두뇌공화국에 입사했다.
> 주인의 무의식 하나하나가 당신의 업무이고, 혼자서는 아무것도 해결할 수 없다.

플레이어는 6개 국 중 하나를 골라(=종족 선택) 입사한 **신입 부서원**.
주인의 하루에서 쏟아지는 민원을 **다른 부서와 협력**해 해결하며,
급여(뇌화)와 인지도(방송 출연)로 공화국을 키운다.

## 2. 코어 루프 — 주인의 하루 (W12)

```
[출근] 공화국 전경(홈) — 국 건물들, 오늘의 뉴스
   ↓
[민원 러시] 주인의 하루가 흐르며 민원 접수 (아케이드 본편)
   민원마다 "필요 부서" 2~3개 표시
   → 해당 부서를 순서대로 호출해 부서별 조작 수행 = 협력 콤보
   → 시간 내 완수 = 해결 / 초과 = 폭주(주인 멘탈 하락)
   ↓
[방송·정산] 뇌보도국 뉴스 — 오늘의 활약 부서 인터뷰(명예 시스템)
   급여 지급 + 활약 국 인지도 상승
   ↓
[성장] 뇌화로 국 업그레이드 → 건물 성장, 새 부서 개설(1,428 진행도),
   민원 유형·난이도 확장 → 다음 하루
```

## 3. 오픈맵 협력 콤보 — 코어 메커닉 (W1·W7·W9·W10)

**공화국 도시(두 개의 거리 × 6국 청사)가 곧 플레이 필드다.**
민원 예: **"소개팅 상대의 이름이 기억나지 않습니다!"**
필요 부서: `기억인지국 → 언어표현국`

1. 민원이 접수되면 필요 부서 청사 위에 말풍선(!)이 뜬다.
2. 건물을 탭하면 **내 캐릭터가 거리를 직접 달려간다** — 이동 거리 = 시간 비용,
   동선 판단이 아케이드 실력이 된다. 도착하면 그 국 시민이 마중 나와
   부서 고유 조작을 함께 수행:
   - 기억인지국: **연타** (서고 뒤지기)
   - 신체반응국: **홀드** (심호흡 밸브)
   - 감정사회국: **홀드** (감정 조율)
   - 충동관리국: **스와이프** (유혹 쳐내기)
   - 언어표현국: **2지선다** (올바른 표현 결재)
   - 수면상상국: **스와이프** (잡념 구름 걷기)
3. 순서대로 전부 성공 = 협력 콤보 완성 → 도장 연출, 점수·급여.
   빠를수록 PERFECT (보너스).
4. **호감도**: 함께 일한 부서는 호감도가 쌓여 다음 호출이 빨라진다(달려오는
   시간 단축). 알력 관계(충동관리국 ↔ 스크린타임 계열)는 중재 민원으로 등장.

플레이어 소속 국의 조작은 강화되어 있다(예: 연타 수 감소) — "내 전문 분야" 실감.

## 4. 명예 시스템 = 성장 엔진 (W5)

- 러시 종료 → **뇌보도국 뉴스**: 오늘 가장 활약한 부서 인터뷰 방송.
- 방송에 나온 국은 **인지도** 상승 → 인지도는 국 건물 성장 단계와 직결
  ("주인의 의식에 자리 잡은 만큼 그 파트가 건강해진다").
- 인지도가 높은 국의 민원은 보상 배율 상승 — 선순환.

## 5. 화면 구성

1. **홈(공화국 전경)**: 노을빛 픽셀 시가지 — 6국 건물(성장 단계별) + 중앙 청사.
   내 캐릭터(선택 종족 외형)가 거리에 서 있다. [출근하기] [국 업그레이드] [뉴스]
2. **민원 러시**: 상단 주인 상태(하루 일과 자막 + 멘탈), 중앙 민원 카드(필요
   부서 아이콘 열), 하단 6개 부서 호출 버튼. 담당자들이 달려오는 레인.
3. **뉴스/정산**: 기자 멘트 + 활약 부서 인터뷰 + 급여/인지도 정산.
4. **결과·성장**: 국 레벨업, 부서 개설 카운터(→1,428), 다음 하루.

## 6. 세션 구조 (스코프)

- 1 러시 = 90초 (하루). 데모 목표: 3일차(하루하루 난이도·민원 다양성 상승).
- 미니 목표: 청사 지령(W8) — "이번 하루 PERFECT 3회" 등 보너스 미션.
- 실패 조건: 멘탈 0 (폭주 누적) → 하루 조기 종료(급여 삭감, 게임오버 아님).

## 7. 아트/사운드 (W9·W14)

- 픽셀아트(6px 셀 코드 생성) + 노을빛 팔레트 고정, Galmuri 폰트(OFL).
- 부서원 캐릭터: 국별 종족 특징을 도트로(나이테 귀·발광 돌기·안테나…) — 달리는
  2프레임 애니메이션.
- BGM: 통통 튀는 밝은 루프(WebAudio 합성), 러시 후반 템포 상승.

## 8. 구현 우선순위 (마감 대응)

**P0 (오늘 밤)**: 홈(전경·성장) / 민원 러시(협력 콤보 6부서×3조작) / 정산·뉴스 /
국 업그레이드 / 3일차 루프 / 캐릭터·담당자 도트 / BGM·SFX
**P1 (여유 시)**: 호감도 시스템, 알력 중재 민원, 청사 지령, 소속 국 선택(기본:
기억인지국 고정으로 시작)
**컷 가능**: 부서 개설 상점, 종족별 아바타 커스텀
