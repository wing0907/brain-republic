# 두뇌공화국: 면접 대작전 — 게임 디자인 문서 (GDD)

- 프로젝트: NAN 2026 (NHN Game × AI Hackathon) 사전 과제 — "AI를 활용한 게임 제작"
- 플랫폼: 모바일 웹 (세로 720×1280, 브라우저 즉시 실행) / 데스크톱 마우스 지원
- 장르: 실시간 위기관리 아케이드 (원버튼급 초저난이도 조작 + 고밀도 연출)
- 플레이 타임: 1판 3분 (면접 1회)
- 원작 세계관: 「두뇌공화국」 — 인간의 뇌를 1,428개 부서를 가진 행정 공화국으로 의인화한 오리지널 IP

---

## 1. 컨셉

> 겉으로는 침착한 면접. 뇌 속은 국가 비상사태.

주인공(취준생)이 인생 최대의 면접을 보는 3분 동안, 플레이어는 **뇌정부청사
위기관리 총괄**이 되어 6개 국(局)에서 터지는 위기를 실시간으로 진압한다.
원작 파일럿 에피소드(면접 장면)의 "위기 대응 다큐" 구조를 그대로 게임 루프로
옮긴 것으로, 세계관의 핵심 재미 — *"무의식적 반응 하나하나가 시민들의 업무"* —
를 조작감으로 체험하게 한다.

**차별점**
- 감정 의인화(인사이드 아웃류)가 아닌 **행정 시스템 패러디**: 위기가 "민원·공문·결재"의 형태로 밀려온다.
- 부서명 자체가 개그: 눈물참기훈련팀, 말실수팀, 핸드폰중독관리팀…
- "아 나도 저런 순간 있었는데" — 면접이라는 보편 경험 기반의 즉각 공감.

## 2. 코어 루프

```
면접 질문 시작(웨이브)
  → 6개 국에서 위기 카드 스폰
  → 플레이어가 카드별 상호작용(탭/연타/홀드/스와이프/선택)으로 해결
  → 해결: 점수+콤보+멘탈 소폭 회복 / 방치: 폭주 → 멘탈 대미지
  → 3분 생존 시 면접 종료 → 등급 판정(S~F) + 부서 활약 랭킹
  → 멘탈 0 → 면접 폭망(즉시 종료) → 재도전
```

## 3. 화면 구성 (세로 1화면)

```
┌──────────────────────────┐
│ 현실 뷰(면접장 실루엣)          │ ← 면접관 질문 자막, 지원자 상태 연출
│ 멘탈 게이지 ████████░░       │
├──────────────────────────┤
│  기억인지국   │  신체반응국   │
│──────────────────────────│
│  감정사회국   │  충동관리국   │   ← 6개 국 패널(2×3 그리드)
│──────────────────────────│
│  언어표현국   │  수면상상국   │
├──────────────────────────┤
│ 남은 시간 · 점수 · 콤보          │
└──────────────────────────┘
```

위기 카드는 해당 국 패널 위에 팝업으로 등장하며, 카드마다 자체 타이머 링이
줄어든다. 타이머 소진 = 폭주(멘탈 대미지 + 현실 뷰에 연출 반영).

## 4. 6개 국 위기와 상호작용

| 국 | 대표 위기(부서) | 상호작용 | 조작 의미 |
|---|---|---|---|
| 기억인지국 | "지원동기 서류 분실!" (기억보관팀) | **연타** (서고 뒤지기) | 기억을 급하게 끄집어냄 |
| 신체반응국 | "손발 저림 수치 폭주!" (손발저림관리팀) | **홀드** (심호흡 밸브) | 지그시 눌러 진정 |
| 감정사회국 | "눈물 게이트 붕괴 직전!" (눈물참기훈련팀) | **홀드** (게이트 보강) | 꾹 참기 |
| 충동관리국 | "핸드폰 확인 충동 유입!" (핸드폰중독관리팀) | **스와이프** (알림 밀어내기) | 유혹 쳐내기 |
| 언어표현국 | "말실수 파일 발송 3초 전!" (말실수팀) | **2지선다 탭** (올바른 단어 결재) | 발화 검열 |
| 수면상상국 | "공상 구름 상영 시작!" (꿈제작팀) | **스와이프** (구름 걷어내기) | 딴생각 차단 |

- 조작은 3계열(탭/홀드/스와이프)로 수렴 — 첫 판에 학습 완료되는 난이도.
- 언어표현국 2지선다는 유머 담당: "저는 **성실**한 지원자입니다" vs "저는 **부실**한 지원자입니다".

## 5. 웨이브 = 면접 질문 (3분 구성)

| 구간 | 질문 | 강도 |
|---|---|---|
| 0:00–0:30 | "자기소개 부탁드립니다" | 튜토리얼 밀도, 단일 스폰 |
| 0:30–1:10 | "지원 동기가 무엇인가요?" | 기억인지국 집중 스폰 |
| 1:10–1:50 | "갈등 경험을 말해보세요" | 감정·신체 동시 스폰 시작 |
| 1:50–2:30 | "본인의 단점은?" | 언어표현국 2지선다 비중 증가 |
| 2:30–3:00 | "마지막으로 하고 싶은 말은?" | 전 부서 러시(피날레) |

질문 전환 시 현실 뷰 자막 + 사이렌 연출로 웨이브 리듬을 시각화.

## 6. 자원/판정

- **멘탈 게이지** 100 시작. 폭주 1회 −12~−18, 해결 시 +2. 0이면 즉시 종료.
- **콤보**: 연속 해결 시 배율 ↑ (최대 ×4), 폭주 시 리셋.
- **등급**: 최종 점수 + 멘탈 잔량으로 S/A/B/C/F — "합격 통보"부터 "다음 기회에…"까지.
- **부서 활약 랭킹**(결과 화면): 원작의 "이달의 등장 횟수" 명예 시스템 오마주.
  가장 많이 해결/폭주한 부서를 뉴스 인터뷰 형식으로 표창·문책.

## 7. 아트 디렉션

원작 아트 가이드(뇌 주름 지형 + 따뜻한 노을빛 오렌지-핑크 톤)를 모바일
그래픽으로 번안. **외부 에셋 0** — 전부 코드 드로잉(Phaser Graphics/Canvas 텍스처).

- 배경: 짙은 보라~네이비, 뇌 주름 곡선 실루엣.
- 국 패널: 국별 고유색 (기억=세피아, 신체=레드코랄, 감정=아쿠아, 충동=네온퍼플, 언어=옐로, 수면=인디고).
- 위기 카드: 공문서/결재판 모티프 + 타이머 링.
- 사운드: WebAudio 신스 — 사이렌, 도장 쾅(해결), 서류 찢김(폭주), 콤보 차임.

## 8. 기술 설계

- Phaser 3 + Vite, 씬 구성: `Boot → Title → Game → Result`.
- `src/data/bureaus.js`: 6개 국·부서·위기 대사 데이터 (세계관 데이터 분리 → 콘텐츠 확장 용이, "1,428개 부서" 확장성 반영).
- 이벤트 스포너: 웨이브 테이블 기반 가중 랜덤, 동시 활성 카드 수 상한(2→4 점증).
- 입력: Phaser 포인터 이벤트로 탭/홀드/스와이프 판별 (모바일 터치 = 마우스 동일 처리).
- 저장: `localStorage` 최고 기록.

## 9. AI 활용 계획 (사전 과제 요건)

- 기획·코드·밸런싱·문서 전 과정 Claude Code(claude-fable-5)로 제작.
- 세계관 원작 문서 → 게임 메커닉 번안, 위기 대사 대량 생성(부서별 바리에이션).
- 상세 프롬프트·활용 내역은 `docs/AI_TECH_DOC.md`에 기록 (제출물 4번).

## 10. 예선 스코프 (마감 8/10) 및 컷 라인

**Must**: 코어 루프(6국 스폰/3조작/멘탈/3분/등급), 타이틀·결과 씬, 모바일 터치, 사운드 최소 4종, 배포 링크.
**Should**: 부서 활약 랭킹, 2지선다 유머 대사 풀, 콤보 연출, 최고기록.
**Cut 가능**: 현실 뷰 애니메이션 고도화, 업그레이드/메타 진행, 다국어.
