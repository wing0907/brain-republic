- 팀명: **뇌지컬연구소**

- 출품작: 두뇌공화국: 신입 공무원 분투기

## 2. 팀원별 역할

| 이름 | 담당 역할 | 실제 맡아 구현한 영역 |
|---|---|---|
| **성지은** | **원작 기획 / 크리에이티브 디렉터** | 오리지널 세계관 「두뇌공화국」 창작(6개 국 행정 체계·종족 설정·명예 시스템·아트 톤). **본 게임은 성지은의 기획으로부터 탄생한 작품**이며, "세계관 우선" 원칙과 게임의 세 기둥(나라 키우기 × 부서원 시점 × 부서 협력)을 정의하고 세계관 정합성을 기준으로 프로토타입을 평가·최종안을 확정 |
| **장우진** (GitHub: wing0907) | 개발 / AI 활용 총괄 | AI 에이전트(Claude Code) 지휘 — 대회 규정 분석, 세계관 분석 문서화, 게임 코드·픽셀아트·사운드 생성, 헤드리스 QA, GitHub 운영(커밋·배포)과 제출물 관리 |

## 3. 협업·분업 방식

- **세계관 → 기획 → 구현 사이클**: 성지은이 세계관과 방향을 정의하면 AI가
  분석·설계·구현하고(장우진 지휘), 팀이 세계관 정합성을 검수해 반복.
  5개 프로토타입을 거쳐 최종안을 선택·재구축.
- **개발 관리**: GitHub 저장소 커밋 이력으로 전 과정 기록.
- **AI 협업 구조**: 상세는 「AI 활용 기술 문서」 참조.
