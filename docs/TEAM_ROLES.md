## 2. 팀원별 역할

| 이름 | 담당 역할 | 실제 맡아 구현한 영역 |
|---|---|---|
| **성지은** | **원작 기획 / 크리에이티브 디렉터** | 오리지널 세계관 「두뇌공화국」 창작(6개 국 행정 체계, 부서 설정, 명예 시스템, 아트 디렉션 톤). **본 게임은 성지은의 기획으로부터 탄생한 작품**으로, 세계관→게임 번안의 방향(면접 에피소드의 게임화, 부서 개그 코드, 결과 화면의 인사발령 연출)을 결정하고 전체 결과물의 기획 정합성을 검수 |
| **장우진** (GitHub: wing0907) | 개발 / AI 활용 총괄 | AI 에이전트(Claude Code) 지휘 — 대회 규정 분석, 게임 코드 생성, 프로시저럴 아트·사운드, 헤드리스 QA, 밸런싱 지시 및 검수. GitHub 저장소 운영(브랜치 전략·PR·배포), 빌드/제출물 관리 |

## 3. 협업·분업 방식

- **기획 → 구현 사이클**: 성지은이 세계관·연출 방향을 정의하면, 개발 담당이 AI
  에이전트를 지휘해 메커닉·코드로 구현하고, 기획자가 원작 정합성을 검수하는
  사이클로 진행.
- **개발 관리**: GitHub 저장소에서 feature branch → Pull Request → 리뷰 → merge
  흐름으로 진행. 전체 커밋 기록이 저장소에 보존되어 있음.
- **AI 협업 구조**: 팀원이 방향·요구사항을 결정하고 AI 에이전트(Claude Code)가
  리서치·코드·테스트를 수행, 팀원이 결과물을 검수. (상세: 「AI 활용 기술 문서」)
