# 세계관 심층 분석 — 게임 요소 추출

원작: https://portfolio-worldview.vercel.app/ (기획 성지은)
방법: 세계관의 각 설정을 원문 그대로 수집하고, 각각이 어떤 게임 메커닉으로
번역될 수 있는지 1:1 매핑한다. **게임의 모든 규칙은 이 표에서 출발한다.**

> 참고: 표의 우측 열은 프로토타입 과정에서 실험한 **번역 후보**들이다.
> 최종작 「부서대전」이 채택한 항목은 2절에 정리 — W1(공감 소재)·W6(부서
> 로스터)·**W7(알력 = 대전 구도, 핵심)**·W9(뇌 주름 전장)·W12(에피소드
> 구조)·W13(공감 유머)·W14(노을 팔레트).

## 1. 세계관 → 게임 요소 매핑

| # | 원작 설정 (원문 요지) | 게임 요소로의 번역 |
|---|---|---|
| W1 | "무의식적 반응 하나하나가 시민들이 수행하는 업무" | **민원 시스템** — 주인의 일상 순간(이름 기억 안 남, 눈물 참기…)이 민원서로 접수되고, 플레이어가 처리하는 '업무'가 됨 |
| W2 | 시민(어린이·청년·노인)이 "원하는 부서에 취업하기 위해 경쟁" | **플레이어 = 신입 공무원** — 국(종족)을 선택해 입사하는 시작 서사. 승진(직급)이 성장축 |
| W3 | 6개 국 = 각각 다른 종족, "직업 선택이 곧 종족 귀속" | **국 선택 = 캐릭터 외형/소속** — 선택한 국의 종족 특징(나이테 귀, 발광 돌기…)을 가진 아바타 |
| W4 | "뇌 안 화폐를 벌어 소비 — 인간 사회와 동일" | **뇌화(화폐) 경제** — 민원 처리 급여 → 사무실 업그레이드/부서 개설에 소비 |
| W5 | 명예 시스템: 방송 출연 → 인지도 → "주인의 의식에 깊이 자리 잡음" → 실제 삶에 자주 등장 → **그 파트의 뇌 건강 향상 = 시민들의 생명** | **인지도(등장률) 게이지 = 국 성장·생존 축** — 실적을 올리면 방송(뉴스 배너)에 출연하고, 인지도가 오른 국은 건물이 성장. 게임의 핵심 선순환 |
| W6 | 1,428개 팀/부서 (콘텐츠 소재 창고) | **부서 해금 진행도** — 성장할수록 새 부서가 개설되어 새 민원 유형 등장. 1,428을 향한 카운터 |
| W7 | 부서 간 알력: "핸드폰중독관리팀 vs 스크린타임을 늘리려는 옆 부서" | **대전(對戰) 구도 — 최종작 핵심 채택**: 목표 상충 부서 간 1:1 턴제 포격 대결. (초기 후보: 갈등 중재 이벤트) |
| W8 | 뇌정부청사: 모든 것을 감시하다 "지금이야, 이렇게 행동해" 최종 신호 | **본부 지령** — 러시 중 청사가 내리는 특별 지령(보너스 목표), 스테이지 클리어 판정의 주체 |
| W9 | 국별 환경: 서고/덩굴관/웅덩이/네온 번화가/안테나탑/안개 구름 지대 | **국별 비주얼 테마** — 배경·지형·색채로 번역. 최종작에선 뇌 주름 능선이 파괴 가능한 전장 |
| W10 | 국별 시민 신체 특징 (업무의 은유) | **부서별 조작 개성** — 기억=연타(서고 뒤지기), 신체=홀드(심호흡), 감정=홀드(참기), 충동=스와이프(쳐내기), 언어=선택(결재), 수면=스와이프(구름 걷기) |
| W11 | 파일럿: 다큐/기자 인터뷰 형식 (세계관 각인용) | **뉴스 프레임** — 뇌보도국 뉴스가 하루의 시작/끝을 감싸고, 명예 시스템(방송 출연)과 직결 |
| W12 | 확장 계획: "각 부서 시민들의 일상(슬라이스 오브 라이프)" | **하루 단위 루프** — 게임의 시간 단위는 '주인의 하루'. 출근 → 민원 러시 → 방송/정산 → 성장. 에피소드 확장 여지 |
| W13 | 기획배경: "반전이 아닌 공감" — 디테일과 공감 유머 | **민원 카피라이팅 원칙** — 모든 민원은 "아 나도 저런 순간 있었는데"가 되도록 일상 순간에서 출발 |
| W14 | 아트: 따뜻한 노을빛(오렌지-핑크) 고정, 유기적 자연 재질 | **팔레트 고정** — 노을빛 기조의 아트 팔레트 고정 |

## 2. 최종작 「부서대전」이 채택한 기둥 (기획 결정)

1. **알력이 곧 게임** — W7: 원작이 명시한 "핸드폰중독관리팀 vs 스크린타임 부서"의
   목표 상충을 **1:1 턴제 포격 대결**로 직역. 고전 아틸러리 장르의 검증된
   "단순·중독" 문법에 세계관을 이식했다.
2. **행정 패러디가 전투 언어** — 기획배경 B: 무기는 결재 도장, 승리는
   "결재 서류에 깔렸다" — 싸움조차 관공서 언어로.
3. **6라운드 = 취침 전쟁 에피소드** — W1·W12·W13: 상대 순서(릴스 유혹→야식→
   이불킥→월요일 걱정→아무말 후회→백일몽)가 잠들기 전 침입 사고의 실제 순서.
   원작 파일럿과 같은 "한 순간의 에피소드" 구조이자 공감 유머 원칙 준수.
4. **무대와 날씨** — W9·W14: 파괴되는 뇌 주름 능선 전장 + 노을빛 팔레트,
   바람은 "주인님의 변덕". W6: 라운드 로스터 확장 = 1,428개 부서 소재 창고.
