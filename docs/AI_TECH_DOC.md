# AI 활용 기술 문서

**NAN 2026 — NHN Game × AI Hackathon 사전 과제 | 두뇌공화국: 부서대전**
**팀 뇌지컬연구소 (성지은 · 장우진)**

---

## 1. 개요

본 프로젝트는 **세계관 분석 → 기획 → 구현 → 아트/사운드 → QA → 문서까지 전
과정을 AI 에이전트(Claude Code)와의 협업으로 제작**했습니다. 사람이 세계관과
방향을 결정하고, AI가 분석·설계·코드·검증을 수행하는 페어 구조입니다.

| 항목 | 내용 |
|---|---|
| 주 사용 AI | Claude Code (Anthropic, claude-fable-5) — 터미널 코딩 에이전트 |
| 활용 범위 | 대회 규정 분석, 세계관 심층 분석, 기획 번안, 전체 게임 코드, 프로시저럴 아트/신스 사운드, 탄도 물리·AI, 헤드리스 QA, 배포 자동화, 제출 문서 |
| 사람의 역할 | 원작 세계관 창작·기획 방향 결정(성지은), 프로토타입 평가·최종안 선택·AI 지휘(장우진), 영상 촬영·신청 제출 |

## 2. 세계관 우선 방법론 (본 프로젝트의 핵심 프로세스)

팀은 "게임의 모든 규칙은 세계관에서 나와야 한다"는 원칙을 세웠고, AI가 이를
프로세스로 구현했습니다:

1. **세계관 심층 분석**: AI가 원작 사이트를 정밀 분석해 설정 14개(W1~W14)를
   추출하고, 각각을 게임 메커닉 후보로 번역한 매핑 문서
   (`docs/WORLDBUILDING.md`)를 작성. 최종작에 채택된 예:
   - "부서 간 알력: 핸드폰중독관리팀 vs 스크린타임 부서"(W7) → **1:1 대전 구도**
   - "행정 시스템 패러디"(기획배경) → **결재 도장 포탄**, "결재 서류에 깔렸다" 연출
   - "뇌 주름 지형·노을빛 팔레트"(W9·W14) → 파괴 가능한 발광 능선 전장
   - 그 외 후보(민원/명예/경제 시스템 등)는 이전 프로토타입들에서 실험
2. **기획 확정**: 팀이 방향("포트리스류의 단순·중독 문법 × 부서 알력 W7")을
   결정하면, AI가 매핑 문서를 근거로 코어 루프를 설계(`docs/GDD.md`).
3. **구현**: 데이터(알력 매치업·밸런스)와 로직을 분리한 구조로 AI가 전체 코드 작성.

### 반복 설계 이력 (정직한 기록)
최종안에 도달하기까지 AI와 함께 **여러 장르의 프로토타입**(위기 대응 아케이드,
경영 시뮬레이션, 엔드리스 러시, Unity 6 기반 3D 스테이지 캠페인, 오픈맵 협력
아케이드 등)을 제작·플레이테스트했고, 팀은 "단순하지만 중독적인 게임성"과
"세계관 정합성"을 기준으로 최종 형태(부서대전)를 선택 — 검증된 고전 문법에
세계관을 이식하는 방식으로 하루 만에 재구축했습니다. 이 반복 전체가 AI 협업의
속도를 보여줍니다.

## 3. 단계별 AI 활용

- **규정 분석**: 공식 사이트가 JS 렌더링 SPA여서 AI가 번들을 파싱해 제출물
  5종 규격·마감·심사 계정 등 규정 전문을 추출.
- **프로시저럴 아트**: 이미지 파일 없이 전량 코드 드로잉 — 노을 그라데이션
  하늘(태양 글로우·구름·별), 국별 컬러 블롭 마스코트(포신 장착), 결재 도장
  포탄, 발광 능선 지형, UI 일체.
- **물리·AI**: 자체 탄도 시뮬레이션(중력+바람 적분), 하이트맵 지형 파괴
  (크레이터), 적 AI는 60샘플 탄도 탐색 후 라운드별 오차(±16°→±3.5°) 적용.
- **신스 사운드**: WebAudio 합성 — 발사/폭발/직격/승패 징글 + 마이너 펜타
  BGM 루프. 음원 파일 0.
- **헤드리스 QA**: Playwright(Chromium)로 실제 빌드를 구동, 탄도 탐색으로
  정확 사격을 재현해 직격 대미지·턴 교대·AI 반격·승리 흐름을 수치 검증,
  콘솔 에러 0 확인.
- **배포**: GitHub Pages 배포 자동화(`npm run deploy`), 라이브 URL 재검증.

## 4. 아키텍처

```
src/
  config.js            물리·밸런스 상수 (중력/바람/대미지/라운드 AI 오차)
  data/matchups.js     알력 매치업 6종 — 부서명/색/소개/도발 (세계관 데이터)
  scenes/
    BootScene.js       프로시저럴 텍스처 생성
    TitleScene.js      타이틀 (포물선 데모 연출)
    BattleScene.js     포격전 — 지형/조준/탄도/폭발/AI/라운드 흐름
  systems/
    art.js             스무스 벡터 아트 (하늘/블롭/포탄/버튼)
    audio.js           신스 SFX + BGM 스케줄러
```
