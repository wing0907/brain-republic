# AI 활용 기술 문서

**NAN 2026 — NHN Game × AI Hackathon 사전 과제 | 두뇌공화국: 신입 공무원 분투기**
**팀 뇌지컬연구소 (성지은 · 장우진)**

---

## 1. 개요

본 프로젝트는 **세계관 분석 → 기획 → 구현 → 아트/사운드 → QA → 문서까지 전
과정을 AI 에이전트(Claude Code)와의 협업으로 제작**했습니다. 사람이 세계관과
방향을 결정하고, AI가 분석·설계·코드·검증을 수행하는 페어 구조입니다.

| 항목 | 내용 |
|---|---|
| 주 사용 AI | Claude Code (Anthropic, claude-fable-5) — 터미널 코딩 에이전트 |
| 활용 범위 | 대회 규정 분석, 세계관 심층 분석, 기획 번안, 전체 게임 코드, 프로시저럴 픽셀아트/신스 사운드, 헤드리스 QA, 배포 자동화, 제출 문서 |
| 사람의 역할 | 원작 세계관 창작·기획 방향 결정(성지은), 프로토타입 평가·최종안 선택·AI 지휘(장우진), 영상 촬영·신청 제출 |

## 2. 세계관 우선 방법론 (본 프로젝트의 핵심 프로세스)

팀은 "게임의 모든 규칙은 세계관에서 나와야 한다"는 원칙을 세웠고, AI가 이를
프로세스로 구현했습니다:

1. **세계관 심층 분석**: AI가 원작 사이트를 정밀 분석해 설정 14개(W1~W14)를
   추출하고, 각각을 게임 메커닉 후보로 번역한 매핑 문서
   (`docs/WORLDBUILDING.md`)를 작성. 예:
   - "무의식적 반응 하나하나가 시민들의 업무" → 민원 시스템
   - "방송 출연 → 인지도 → 주인의 의식에 자리 → 뇌 건강 = 생명" → 명예
     시스템을 성장 엔진으로
   - "시민이 부서 취업 경쟁" → 플레이어 = 신입 부서원 시점
2. **기획 확정**: 팀이 세 기둥(나라 키우기 큰 틀 × 부서원 시점 × 부서 협력)을
   결정하면, AI가 매핑 문서를 근거로 코어 루프를 설계(`docs/GDD.md` — 모든
   규칙에 W# 근거 표기).
3. **구현**: 데이터(민원·부서·종족)와 로직을 분리한 구조로 AI가 전체 코드 작성.

### 반복 설계 이력 (정직한 기록)
최종안에 도달하기까지 AI와 함께 **5개의 프로토타입**(위기 대응 아케이드,
경영 시뮬레이션, 엔드리스 러시, Unity 6 기반 3D 스테이지 캠페인, 에피소드형
아케이드)을 제작·플레이테스트했고, 팀은 "세계관과 게임 규칙의 정합성"을
기준으로 전면 재설계를 결정 — 세계관 우선 방법론으로 현재 게임을 하루 만에
재구축했습니다. 이 과정 전체가 AI 협업의 반복 속도를 보여줍니다.

## 3. 단계별 AI 활용

- **규정 분석**: 공식 사이트가 JS 렌더링 SPA여서 AI가 번들을 파싱해 제출물
  5종 규격·마감·심사 계정 등 규정 전문을 추출.
- **프로시저럴 픽셀아트**: 이미지 파일 없이 6px 셀 스냅 도트 드로잉을 코드로
  생성 — 노을 디더링 하늘, 국별 청사(3단계 성장), **종족별 시민 캐릭터 6종**
  (원작 설정 반영: 나이테 귀·덩굴 무늬·반투명·발광 돌기·안테나·반딧불 점,
  2프레임 달리기 애니메이션), 민원 카드, UI 일체.
- **신스 사운드**: WebAudio 오실레이터/노이즈 실시간 합성 — SFX 14종 +
  BGM(96bpm 스윙, 펜타토닉 스타카토 플럭의 "통통 튀는 밝은" 루프, 러시 종반
  템포 가속).
- **헤드리스 QA**: Playwright(Chromium)로 실제 빌드를 구동해 입사→홈(튜토리얼)
  →러시(협력 콤보 3건 자동 수행·점수 검증)→뉴스(급여·명예 정산 수치 검증)→
  성장(업그레이드) 전 루프를 자동 검증, 콘솔 에러 0 확인.
- **배포**: GitHub Pages 배포 자동화(`npm run deploy`), 라이브 URL 재검증.

## 4. 아키텍처

```
src/
  config.js            밸런스 상수 (근거: GDD/W# 매핑)
  data/
    bureaus.js         6개 국 — 색/종족/조작/환경 (세계관 데이터)
    complaints.js      민원 17종 + 알력 2종 + 뉴스 멘트
  scenes/
    BootScene.js       텍스처·애니메이션 생성
    TitleScene.js      타이틀 (걸어다니는 시민들)
    HomeScene.js       공화국 전경 — 성장/업그레이드 (나라 키우기)
    RushScene.js       민원 러시 — 협력 콤보 (코어 루프)
    NewsScene.js       뇌보도국 뉴스 — 명예 시스템 정산
  systems/
    art.js             프로시저럴 픽셀아트 (6px 셀)
    audio.js           신스 SFX + BGM 스케줄러
    save.js            localStorage 세이브 + 부서 카운터
```
