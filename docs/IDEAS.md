## 오픈맵 아케이드 (2026-08-09, 우진)

> "아케이드 형식의 오픈맵 같은 게임이면 좋을 거 같은데"

- 공화국 도시 전체가 플레이 필드 — 신입 캐릭터를 직접 조작(가상 스틱/탭 이동)해
  거리를 뛰어다닌다.
- 민원이 도시 곳곳(해당 국 청사 앞)에 실시간 팝업 → **현장으로 직접 달려가서**
  협력 콤보 수행. 거리 = 시간 압박, 동선 최적화가 실력이 됨.
- 다른 부서원 NPC들이 거리를 오가고, 호출하면 같이 뛰어와 주는 협력 유지.
- 세계관 정합: W1(업무 현장), W9(국별 환경을 실제 지역으로 — 서고 골목,
  네온 번화가, 안개 지대…), W12(하루 루프 유지).
- 본선 48h에서: 현 코드베이스의 러시 로직·캐릭터·픽셀 타일을 재사용하면
  하루 안에 프로토타입 가능. 주제 발표와 결합할 것.

## 미니게임 확장 3종 (2026-08-09, 우진)

> "미로찾기 같은 걸로 하면 어때? 블록쌓기나 벽타고 올라가면서 장애물 피하는 것도"

- **미로찾기**: ✅ **구현됨 (2026-08-09)** — 기억인지국 도착 시 서고 미로(5×5 DFS,
  스와이프 이동)로 기억 조각(◆) 인출. 부서별 전용 미니게임 구조의 첫 실증.
- **블록쌓기**: 언어표현국 문장 조립탑 — 단어 블록을 쌓아 문장 완성, 무너지면 말실수.
- **벽타기 장애물**: 신체반응국 혈관 등반 — 심박 리듬에 맞춰 덩굴관을 오르며
  스트레스 장애물 회피.
- 셋 다 현 오픈맵의 "청사 도착 → 미니 인터랙션" 슬롯에 꽂히는 구조 —
  본선/차기 버전에서 부서별 전용 미니게임으로 확장하면 1,428개 부서 콘텐츠
  로드맵(W6)과 정확히 맞물린다.
