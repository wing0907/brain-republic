## 1. 게임 제목 및 한 줄 소개

**두뇌공화국: 신입 공무원 분투기** (Brain Republic: Rookie Officer)

> 당신은 오늘 두뇌공화국에 입사했다. 주인님의 무의식 하나하나가 당신의
> 업무이고 — **혼자서는 아무것도 해결할 수 없다. 부서와 협력하라!**

인간의 뇌를 1,428개 부서의 행정 공화국으로 의인화한 오리지널 세계관
「두뇌공화국」(원작 기획: 성지은, https://portfolio-worldview.vercel.app/)을
**세계관 우선 방법론**으로 게임화했습니다: 원작의 설정 14개를 게임 요소로 1:1
번역한 분석 문서(`docs/WORLDBUILDING.md`)가 모든 규칙의 근거입니다 — 민원
시스템(무의식=업무), 협력 콤보(부서 조직), 명예 시스템(방송 출연=성장),
뇌화 경제, 1,428개 부서 확장.

## 2. 게임 방법

### 목표
신입 부서원이 되어 주인님의 하루(민원 러시)를 버텨내고, 급여(뇌화)와
인지도(방송 출연)로 **공화국을 1,428개 부서 도시로 키우는 것**.

### 코어 루프 — 주인의 하루
1. **출근**: 공화국 전경(홈)에서 [출근하기] — 하루 90초의 민원 러시 시작.
2. **협력 콤보(핵심)**: 민원 카드마다 "필요 부서"가 순서대로 표시됩니다.
   - 해당 부서 버튼을 **순서대로 호출** → 담당자 캐릭터가 화면으로 달려옵니다.
   - 부서별 고유 조작을 수행: 기억 **연타** · 신체/감정 **길게 누르기** ·
     충동/상상 **스와이프** · 언어 **2지선다 결재**
   - 모든 단계 성공 = 협력 콤보 완성(결재 도장). 빠르면 **PERFECT** ×1.5,
     연속 해결로 **콤보 배율**(최대 ×4).
   - 엉뚱한 부서를 부르면 주인님 멘탈이 깎입니다. 시간 초과 = 민원 폭주.
   - 내 소속(기억인지국) 업무는 **전문 분야 보정** — 내가 직접 뛰어가 처리!
3. **뇌보도국 9시 뉴스(정산)**: 최다 활약 부서가 **방송 인터뷰**에 출연 —
   원작 명예 시스템 그대로, 방송에 나온 국은 인지도가 오르고 도시에서
   별이 빛납니다. 급여 지급.
4. **성장**: 뇌화로 국 청사를 확장(건물이 실제로 높아짐) → 개설 부서 수가
   1,428을 향해 증가, 다음 날은 더 어려운 민원(협력 부서 3개)이 옵니다.

### 종료 조건
- 하루 90초 생존 → 뉴스 정산 → 다음 일차 (1~3일차 난이도 상승, 이후 반복).
- 주인님 멘탈 0 → 조기 퇴근(급여만 정산, 게임오버 없음). 세이브 자동 저장.

### 민원 예시 (원작의 "공감 유머" 원칙)
- "소개팅 상대의 이름이 기억나지 않습니다!" → 기억 + 언어 협력
- "새벽 2시, 릴스가 한 개만 더를 외칩니다" → 충동 + 상상 협력
- "면접 질문: 본인의 단점은?" → 기억 + 감정 + 언어 풀 협력
