# 두뇌공화국: 면접 대작전

**NAN 2026 — NHN Game × AI Hackathon 사전 과제 | 게임 소개 및 설명 문서**

---

## 1. 게임 제목 및 한 줄 소개

**두뇌공화국: 면접 대작전** (Brain Republic: Interview Crisis)

> 겉으로는 침착한 면접, 뇌 속은 국가 비상사태 — 3분 동안 뇌 공화국 6개 국(局)의 위기를 진압하고 멘탈을 사수하는 모바일 실시간 위기관리 아케이드.

인간의 뇌를 1,428개 부서를 가진 거대 행정 공화국으로 의인화한 오리지널 세계관
「두뇌공화국」을 게임으로 옮겼습니다. 무의식적 반응 하나하나가 뇌 속 공무원들의
업무라는 설정 위에서, 플레이어는 취준생의 면접 3분을 뒤에서 지탱하는
**뇌정부청사 위기관리 총괄**이 됩니다.

## 2. 게임 방법

### 목표
면접이 진행되는 **3분(실시간)** 동안 뇌 속 6개 국에서 터지는 위기 카드를 해결하여
**멘탈 게이지(100)가 0이 되지 않게 사수**하고, 최고 등급(S)의 면접 결과를 받아내는 것.

### 조작 (모바일 터치 / 데스크톱 마우스 동일)

| 국(局) | 위기 예시 | 조작 |
|---|---|---|
| 기억인지국 | "지원동기 서류 분실!" | **연타** — 빠르게 여러 번 탭 (서고 뒤지기) |
| 신체반응국 | "손발 저림 수치 폭주!" | **홀드** — 길게 눌러 심호흡 |
| 감정사회국 | "눈물 게이트 붕괴 직전!" | **홀드** — 길게 눌러 게이트 보강 |
| 충동관리국 | "핸드폰 확인 충동 유입!" | **스와이프** — 카드를 밀어내기 |
| 언어표현국 | "말실수 파일 발송 3초 전!" | **2지선다 탭** — 올바른 단어를 결재 |
| 수면상상국 | "공상 구름 상영 시작!" | **스와이프** — 구름 걷어내기 |

- 위기 카드마다 **타이머 링**이 줄어들며, 시간 내 해결하지 못하면 폭주 → 멘탈 대미지.
- 연속 해결 시 **콤보 배율**(최대 ×4)로 점수가 상승하고, 폭주 시 콤보가 끊깁니다.
- 면접 질문("자기소개 부탁드립니다" → "마지막으로 하고 싶은 말은?")이 웨이브 역할을
  하며, 후반으로 갈수록 위기가 몰아칩니다.

### 종료 조건
- **생존 종료**: 3분 경과 → 최종 점수(+멘탈 잔량 보너스)로 S~F 등급 판정.
- **패배**: 멘탈 게이지 0 → "멘탈 붕괴" 즉시 종료(F).
- 결과 화면에서 원작의 명예 시스템을 오마주한 **뇌정부 인사발령 속보**(이달의 우수
  부서 / 긴급 감사 대상)가 발표됩니다.
