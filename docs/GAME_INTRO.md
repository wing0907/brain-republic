## 1. 게임 제목 및 한 줄 소개

**두뇌공화국: 면접 대작전** (Brain Republic — EP01)

> 겉으로는 침착한 면접, 뇌 속은 국가 비상사태 — 원작 파일럿 에피소드(EP01)를
> 그대로 플레이하는 3분 실시간 위기관리 아케이드.

인간의 뇌를 1,428개 부서의 행정 공화국으로 의인화한 오리지널 세계관
「두뇌공화국」(원작 기획: 성지은)의 **파일럿 에피소드 1화를 충실히 게임화**했습니다.
원작의 훅(면접실→뇌 사이렌) → 위기+기자 인터뷰 → 페이오프 → 클로징·이스터에그
구성이 게임의 인트로 → 본편 → 결과 화면으로 그대로 이어지며, 이후 에피소드는
원작 확장 계획(부서별 슬라이스 오브 라이프)에 따라 순차 공개 구조입니다.

## 2. 게임 방법 (EP01)

### 목표
주인님 인생 최대의 면접 **3분** 동안 뇌정부청사 6개 국(局)에서 터지는 위기를
해결해 **멘탈 게이지(100)를 사수**하고 최고 등급(S)을 받는 것.

### 진행
- 면접관의 질문("자기소개 부탁드립니다" → "마지막으로 하고 싶은 말은?")이
  웨이브가 되어 갈수록 위기가 몰아칩니다.
- 위기 카드는 부서 공문서로 등장 — 카드마다 타이머 링이 줄어들며, 시간 내
  해결하지 못하면 폭주(멘탈 대미지 + 현실의 지원자에게 이상 반응).

### 조작 (터치/마우스 동일)

| 국 | 위기 예시 | 조작 |
|---|---|---|
| 기억인지국 | "지원동기 서류 분실!" | **연타** (서고 뒤지기) |
| 신체반응국 | "손발 저림 수치 폭주!" | **길게 누르기** (심호흡) |
| 감정사회국 | "눈물 게이트 붕괴 직전!" | **길게 누르기** (게이트 보강) |
| 충동관리국 | "핸드폰 확인 충동 유입!" | **스와이프** (밀어내기) |
| 언어표현국 | "말실수 파일 발송 3초 전!" | **2지선다** (올바른 단어 결재) |
| 수면상상국 | "공상 구름 상영 시작!" | **스와이프** (구름 걷어내기) |

- 연속 해결 시 **콤보 배율**(최대 ×4). 폭주하면 콤보가 끊깁니다.
- **PERFECT 판정**: 타이머가 넉넉할 때 해결하면 ×1.5 보너스 — 빠르고 정확할수록 점수가 커집니다.
- **피버 타임**: 콤보 8 달성 시 10초간 점수 ×2 — 화면이 노을빛으로 달아오르고 BGM 템포가 빨라지며 위기가 몰아칩니다.
- **보스 — 압박 면접관**: 마지막 30초, 3단계 압박(꼬리질문 연타 → 정적 속 심호흡 → 마무리 멘트 결재)을 돌파하면 대량 점수, 무너지면 멘탈 -25.

### 종료 조건
- 3분 생존 → 최종 점수(+멘탈 보너스)로 **S~F 등급** 판정.
- 멘탈 0 → "멘탈 붕괴" 즉시 종료.
- 결과 화면: 원작 명예 시스템을 오마주한 **뇌정부 인사발령 속보**(이달의 우수
  부서/긴급 감사 대상) + 기자 클로징 멘트 + 말실수팀 이스터에그.

### 사운드
- 배경음악·효과음 전량 코드 합성(WebAudio) — 원작 사이트의 BGM 가이드("경쾌한"
  톤)에 맞춘 통통 튀고 잔잔한 밝은 루프.

## 3. 번외 실험 모드 (허브에서 진입)

에피소드 허브 하단의 「번외 실험실」에서 같은 세계관의 실험 모드 2종을
플레이할 수 있습니다 (모두 동일 저장소 소스 포함):

- **🏰 왕국 키우기** — 6개 국 청사를 성장시키는 경영 모드. 원작 경제·명예
  시스템을 규칙화("인지도 = 수명", 방치하면 국장이 잊혀져 소멸), 에피소드
  18편·야근 러시 아케이드·스파이 색출 추리 포함.
- **🧊 3D 코어 원정대** (Unity 6 WebGL) — 홀로그램 기억 코어 세계관의 스토리
  캠페인. 에피소드 클리어마다 국장의 능력(도약/질주/방패/시간제동/자석)을
  얻어 다음 스테이지를 돌파. 링크: https://wing0907.github.io/brain-republic/unity/
